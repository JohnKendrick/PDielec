# Examples/Phonopy/Al2O3/Primitive_cell

[Back to Al2O3](../README.md)

Al2O3 Phonopy example using the primitive cell. The directory contains force sets, phonon YAML data and Born charges. The parent README describes the calculation and comparison with the standard cell.

Run the supplied recipe from this directory:

```sh
../../../../pdmake command.pdmake
```

To open the PDGui recipe interactively:

```sh
../../../../pdmake --view command.pdmake
```
