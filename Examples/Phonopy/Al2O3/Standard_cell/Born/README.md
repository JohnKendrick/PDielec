# Examples/Phonopy/Al2O3/Standard_cell/Born

[Back to Standard_cell](../README.md)

Supporting VASP Born-charge calculation for the standard-cell Al2O3 Phonopy example. Inputs and outputs include `INCAR`, `POSCAR`, `KPOINTS`, `OUTCAR` and `vasprun.xml`; `BORN` and `BORN_PDIELEC` retain the Born-charge data.
