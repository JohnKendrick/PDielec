# Examples/Phonopy/Al2O3/Standard_cell

[Back to Al2O3](../README.md)

Al2O3 Phonopy example using the standard cell. The directory contains force sets, phonon YAML data, Born charges and VASP inputs. The parent README describes the calculation and comparison with the primitive cell.

Run the supplied recipe from this directory:

```sh
../../../../pdmake command.pdmake
```

To open the PDGui recipe interactively:

```sh
../../../../pdmake --view command.pdmake
```
