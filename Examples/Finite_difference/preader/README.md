# Examples/Finite_difference/preader

[Back to Finite_difference](../README.md)

Infrared `preader` regression using average masses and Eckart projection. The recipe reads the [shared ZnO JSON dataset](../../Powder_Raman/Finite_difference/finite_difference.json) and compares the CSV output with `command.ref.csv`.

Run the supplied recipe from this directory:

```sh
../../../pdmake command.pdmake
```
