# Examples/Crystal_Raman/Castep-25.12

[Back to Crystal_Raman](../README.md)

CASTEP 25.12 crystal Raman calculation of ZnO. The `raman.castep`, `raman.phonon` and `raman.efield` files supply the response data; `script.py` defines the PDGui scenarios. The directory also retains the geometry optimisation inputs and outputs.

Run the supplied recipe from this directory:

```sh
../../../pdmake command.pdmake
```

To open the PDGui recipe interactively:

```sh
../../../pdmake --view command.pdmake
```
