# Examples/Powder_Raman/QE
## Quantum Espresso calculation on ZnO

The PDGui calculation in script.py calculates the powder Raman spectrum using a DFT calculation on ZnO.
The calculation uses Quantum Espresso as the DFT package to calculate the Raman tensor.
The calculation uses an LDA functional (QE does not support GGA functionals for the calculation of 3rd order derivatives;
however, the check for this was removed in PHonon/PH/phq_setup.f90 - see the QE user forum for more information).
The geometry optimisation must be run first, followed by the Raman phonon calculation.

Any of the following commands will load a complete dataset:

```
pdgui --spectroscopy powder_raman ZnO.xml        # reads ZnO.xml + ZnO.dynG + tensors.xml
pdgui --spectroscopy powder_raman ZnO.dynG       # reads ZnO.xml + ZnO.dynG + tensors.xml
pdgui --spectroscopy powder_raman zno.raman.log  # reads zno.raman.log + ZnO.dynG + tensors.xml
```

If `tensors.xml` is present it supplies higher-precision Born charges and Raman tensors and
is read automatically after the primary file.  Without `tensors.xml` the `.log` file must be
used as it is the only source of the Raman susceptibility tensors.

| **File**              | **Description**                                   |
| --------------------- | ------------------------------------------------- |
| zno.opt.in            | Input for the geometry optimisation |
| zno.raman.in          | Input for the phonon and Raman calculation |
| ZnO.dynG              | The dynamical matrix from the zno.raman.in calculation |
| zno.raman.log         | The output log from the zno.raman.in calculation |
| ZnO.xml               | The xml file generated by the geometry optimisation |
| tensors.xml           | Born charges and Raman tensors, from the _ph0/ph.save/ directory |
| command.pdmake        | pdmake script for the test suite |
| results.ref.xlsx      | reference results for the test suite |
| script.py             | script used by pdgui for the test suite |
