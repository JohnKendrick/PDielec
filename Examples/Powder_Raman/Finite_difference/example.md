# VASP finite-difference powder Raman example

Run `../../../pdmake command.pdmake` here to compare ZnO powder spectra with
the electro-optic contribution off and on against `results.ref.xlsx`.
For an interactive view, run `../../../pdgui -script script.py`.

The local `finite_difference.json` is the shared 21×21×14 VASP ZnO dataset used
by the two `preader` examples. See the
[finite-difference example notes](../../Finite_difference/finite_difference_examples.md) for source
provenance, normalisation, chi2 validation cautions and full test instructions.
