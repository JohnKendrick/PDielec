# Examples/Powder_Raman/Finite_difference

[Back to Powder_Raman](../README.md)

VASP finite-difference ZnO powder Raman example comparing electro-optic contributions off and on. The local `finite_difference.json` is also used by the infrared and Raman reader recipes. See the [example notes](example.md) and [calculation provenance](../../Finite_difference/finite_difference_examples.md).

Run the supplied recipe from this directory:

```sh
../../../pdmake command.pdmake
```

To open the PDGui recipe interactively:

```sh
../../../pdmake --view command.pdmake
```
